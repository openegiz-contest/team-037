# Команда 037: цифровой двойник карьера Актогай на OpenEgiz

Цифровой двойник открытого медного карьера (по мотивам открытых данных о месторождении Актогай,
Восточный Казахстан). В карьере работают 5 экскаваторов и 20 самосвалов. Сульфидная руда идёт
на дробилку и обогатительную фабрику, оксидная — на кучное выщелачивание, вскрыша — в отвал.

Двойник показывает **реальную работу карьера** с системой умной диспетчеризации: каждый рейс
назначается заново с учётом очередей, бункера и склада руды перед фабрикой, качества руды, взрывов и прогноза
отказов по датчикам.

Параметры сверены с открытыми данными о реальном карьере (5 экскаваторов Hitachi, парк CAT 793/785,
глубина до ~230 м, диспетчеризация, контроль усталости и система против столкновений) —
см. [«Сверка с реальным карьером»](SUBMISSION.md#сверка-с-реальным-карьером).

Рядом в фоне считается **теневой расчёт**: та же смена с теми же поломками, дорогами и взрывами,
но по-старому, с самосвалами, закреплёнными за экскаваторами. Диспетчеру он не мешает: его видно
только в разделе «Эффект». Там можно в реальном времени показать руководству, сколько система
экономит в тоннах, минутах простоя и тенге.

Все 100 объектов — двойники в Eclipse Ditto (OpenEgiz). Симулятор публикует их состояние через
MQTT, интерфейс читает его из Ditto, сценарии «что если» отправляются командой в двойник
`org.aktogay:control`.

> Модель построена по открытым данным, операционные данные смоделированы.
> Проект не связан с KAZ Minerals.

## Запуск

Нужны Docker и `make`. Подробные требования, в том числе для Windows/WSL2, описаны в
[OPENEGIZ.ru.md](OPENEGIZ.ru.md).

```bash
sudo apt install -y make   # если make нет (чистая Ubuntu)
make aktogay               # платформа OpenEgiz + двойники карьера + симулятор + 3D-интерфейс + дашборд
```

`make aktogay` выполняет всё сам, вмешательство не нужно:

1. запускает платформу (`make up`): при первом запуске генерирует пароли в
   `deploy/compose/.env`;
2. собирает два образа из `team/aktogay/app`: симулятор на Node.js и веб-интерфейс на nginx.
   Внешние датасеты и модели не скачиваются, нужны только npm-пакеты при сборке;
3. создаёт двойники в Ditto и запускает смену.

В конце печатаются адреса.

После этого `make up` / `make down` поднимают и останавливают карьер вместе с платформой.

| Команда | Что делает |
|---|---|
| `make aktogay-stop` | остановить симулятор карьера; двойники и данные остаются |
| `make down` | остановить всё, данные сохранить |
| `make clean` | остановить и удалить все данные и пароли |

Параметры смены можно задать переменными окружения, например
`AKTOGAY_TRUCKS=25 AKTOGAY_SEED=7 make aktogay`:

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `AKTOGAY_TRUCKS` | число самосвалов на старте (5–30); дальше парк меняется в разделе «Оборудование» | 20 |
| `AKTOGAY_SEED` | сценарий случайных событий | 42 |
| `AKTOGAY_SPEEDUP` | ускорение модельного времени | 10 = x1 в интерфейсе (12-часовая смена ≈ 72 мин); x20 — около 3,5 мин |
| `AKTOGAY_UI_PORT` | порт интерфейса | 8095 |

## Что открыть

| Адрес | Что там |
|---|---|
| **http://localhost:8095** | Главный интерфейс (клик по зданию на 3D — его «внутренний двойник»: мнемосхема дробилки, фабрики, гаража, выщелачивания, отвала) (без видеокарты сам включает лёгкую 3D-графику; вручную — переключатель «Графика» или `?quality=light`), раздел **«Карьер»**: реальный карьер в 3D, показатели смены, графики, прогноз отказов, журнал, кнопки сценариев. Значок «● OpenEgiz · Ditto» означает, что данные идут из платформы |
| http://localhost:8095/#/effect | Раздел **«Эффект»**: реальная работа против теневого расчёта без системы — две 3D-сцены рядом, разница KPI, экономический эффект в ₸/год |
| http://localhost:8095/#/drivers | Раздел **«Водители»**: рейтинг стиля вождения по телеметрии (темп на съездах, резкие торможения, расход в движении, выработка) и кого ставить на длинные спуски с грузом |
| http://localhost:8095/#/geology | Раздел **«Геология»**: где в карьере руда глазами приборов рудного контроля — блочная модель по горизонтам и разрез вглубь, XRF-пробы шлама скважин, которые пробурили буровые станки модели (и куда пойдёт блок: фабрика, выщелачивание, отвал), гиперспектральный скан бортов, электроразведка под дном |
| http://localhost:8095/#/map | Раздел **«Карта ГОК»**: 2D-схема всего комбината — карьер с уступами и живой техникой, дробилка, склад, ОФ-1, выщелачивание, отвал, гараж (живые данные), а также ОФ-2, завод SX-EW и пруды растворов, хвостохранилище, склад концентрата и ж/д, подстанция и ЛЭП, водоводы, склад ВМ, РМЦ, АБК с диспетчерской, лаборатория, склад ГСМ, вахтовый посёлок (условная схема по открытым данным). Виды карты: «Схема» (работает без интернета), «Спутник», «Гибрид», «Рельеф», «Карта» — реальная местность Актогая (Esri World Imagery, OpenTopoMap, OpenStreetMap; нужен интернет), карьер модели совмещён с настоящим по контуру из OpenStreetMap. Слои, масштаб колесом, карточка объекта, переход в «что внутри» и к двойнику |
| http://localhost:8095/#/dispatch | Раздел **«Диспетчер»** (демо-вход: `dispatcher` / `demo`): пульт смены — приказы самосвалам (к экскаватору, на заправку, стоять на стоянке, вернуть системе), сообщения водителям в терминалы, ответы водителей. Приказы идут командами через двойник управления в Ditto и выполняются моделью реального карьера |
| http://localhost:8095/#/terminal | Раздел **«Терминал водителя»** (демо-вход: `driver-101`…`driver-120` / `demo`): планшет в кабине — текущее задание, приказ диспетчера, кнопки «Принял / Заправка / Неисправность», сообщения диспетчера с подтверждением «Прочитал», топливо, груз, усталость |
| http://localhost:8095/#/timeline | Раздел **«Хронология»**: цепочки последствий (происшествие → очереди → бункер → простой фабрики → медь и ₸, рядом — что было бы без системы) и диаграмма Ганта смены по минутам для каждой машины |
| http://localhost:8095/#/fleet | Раздел **«Оборудование»**: парк техники — карточки экскаваторов и самосвалов с состоянием, добавление и вывод машин (экскаватор: материал, горизонт, место на карте карьера, модель по ковшу); вводится с новой смены, двойники создаются и удаляются в Ditto |
| http://localhost:8095/#/twins | Раздел **«Двойники»**: все двойники из Ditto деревом, паспорт (attributes), живые признаки (features) с мини-графиками, связи, сравнение с другим вариантом |
| http://localhost:8095/#/scenarios | Раздел **«Сценарии»**: запуск «что если» с выбором объекта и длительности, текущие отклонения с отменой, сравнение стратегий, история команд |
| **http://localhost:3000/d/aktogay-digital-mine** | Дашборд Grafana «Aktogay — цифровой двойник карьера» (Dashboards → OpenEgiz Examples): показатели из InfluxDB, встроенная 3D-сцена с кнопками сценариев, графики по самосвалам и экскаваторам. Логин `admin`, пароль печатает `make up` (он же в `deploy/compose/.env`) |
| Grafana → приложение **OpenEgiz** → **Twins** | Иерархия двойников: `org.aktogay:aktogay` → два варианта карьера → объекты |
| http://localhost:8080/api/2/things?namespaces=org.aktogay.smart | Двойники напрямую в Ditto API (логин `ditto`, пароль в `deploy/compose/.env`) |

**Как показать за 2 минуты.** Откройте http://localhost:8095 и нажмите «⚠ Поломка»: экскаватор
ломается в обоих карьерах.

- В реальном карьере самосвалы сразу перераспределяются на другие забои.
- В разделе «Эффект» видно, что было бы без системы: самосвалы стоят в очереди к сломанному
  экскаватору, бункер дробилки и склад руды пустеют.

Нажмите «↶ Отменить сценарии», и экскаватор снова в работе. Все сценарии и модули описаны в
[SUBMISSION.md](SUBMISSION.md).

## Содержимое репозитория

| Путь | Что там |
|---|---|
| `team/aktogay/app/src/sim/` | движок симуляции: граф дорог, стратегии диспетчеризации, качество руды, датчики и прогноз отказов, взрывы, KPI и экономика |
| `team/aktogay/app/src/platform/twins.ts` | контракт двойников: объекты, признаки (features), сериализация и восстановление состояния |
| `team/aktogay/app/service/main.ts` | сервис-симулятор: создаёт двойники в Ditto, публикует телеметрию в MQTT, выполняет команды «что если» |
| `team/aktogay/app/src/` | веб-интерфейс (React + Three.js), читает двойники из Ditto |
| `team/aktogay/compose.yml` | подключение сервисов карьера к `make up` (overlay) |
| `team/aktogay/grafana/` | дашборд Grafana и скрипт, который его генерирует |
| `team/aktogay/app/BENCHMARK.md` | сравнение стратегий на 20 сменах |
| `SUBMISSION.md` | описание решения для жюри |
| `presentation.pdf` | презентация |
| `OPENEGIZ.md`, `OPENEGIZ.ru.md` | документация платформы OpenEgiz v1.0.4 |
| `examples/mine/` | Пример рудника от организаторов; в нашем решении не используется |

Решение — ветка `main`.

## Разработка без Docker

```bash
cd team/aktogay/app
npm install
npm test           # тесты движка
npm run dev        # http://localhost:5173 — автономный режим, модель считается в браузере
npm run bench      # бенчмарк стратегий → BENCHMARK.md
```

Если платформа запущена, а в окружении задан `DITTO_BASIC_AUTH` из `deploy/compose/.env`,
`npm run dev` работает с двойниками Ditto.
